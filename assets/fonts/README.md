# Fonts

Subsets of three open fonts, licensed under the SIL Open Font License 1.1
(full texts alongside: `OFL-*.txt`).

| Font | Role | Source |
| --- | --- | --- |
| Instrument Serif | display | https://github.com/google/fonts/tree/main/ofl/instrumentserif |
| Instrument Sans | text | https://github.com/google/fonts/tree/main/ofl/instrumentsans |
| JetBrains Mono | labels and code | https://github.com/google/fonts/tree/main/ofl/jetbrainsmono |

`serif.woff2`, `sans.woff2` and `mono.woff2` are Basic Latin subsets used by
`scripts/stats.py`. The static panels in `assets/*.svg` embed exact glyph subsets,
built by `scripts/build_assets.py`.
