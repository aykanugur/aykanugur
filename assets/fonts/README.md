# Fonts

EB Garamond (Georg Duffner, Octavio Pardo), licensed under the SIL Open Font
License 1.1; the full text is in `OFL-EBGaramond.txt`.
Source: https://github.com/google/fonts/tree/main/ofl/ebgaramond

`garamond.woff2` and `garamond-italic.woff2` are Basic Latin subsets (with small
capitals and old-style figures) used by `scripts/stats.py`. The static pages in
`assets/*.svg` embed exact glyph subsets, built by `scripts/build_assets.py`.
